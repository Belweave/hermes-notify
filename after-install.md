## Next: connect your phone (about 1 minute)

```sh
hermes plugins enable hermes-notify
hermes notify setup
```

`hermes notify setup` signs you in to Notify (free; it creates an account if you don't have one), saves the API key to this profile, turns the plugin on, links you to the phone app, sends a test notification, and sends Hermes's command approvals to your phone (the terminal prompt stays as the fallback).

It works right away, even in open sessions. Try: *"Send me a Notify message when you're done."*
